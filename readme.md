# Amazon UI Clone - Desktop Version

A high-fidelity clone of the Amazon homepage built to practice advanced CSS layouts and design structures. This project focuses on replicating the complex UI components of an e-commerce giant.

## 🚀 Overview
The goal of this project was to master **CSS Flexbox and Grid** by recreating the iconic Amazon desktop interface. It is a static frontend project that focuses on pixel-perfection and visual accuracy.

## ✨ Key Features
- **Complex Navbar:** Replicated the Amazon header with search bar, location pin, and multi-layered navigation.
- **Product Grids:** Used CSS Grid to create a clean, organized product display similar to the original site.
- **Custom UI Elements:** Created custom dropdown menus and hover states for a realistic feel.
- **Optimized for Desktop:** Specifically designed for a seamless experience on widescreen monitors (1920x1080).

## 🛠️ Tech Stack
- **HTML5:** For structured semantic markup.
- **CSS3:** For layout (Flex/Grid) and visual styling.
- **Boxicons:** For professional-grade icons.
